# AgriDoc Backend

This backend provides simple API endpoints for the AgriDoc frontend.

## Install

```bash
cd backend
npm install
```

## Start

```bash
cd backend
npm start
```

## Available endpoints

- `GET /api/status`
- `GET /api/crops`
- `GET /api/listings`
- `POST /api/orders`
- `POST /api/listings`
- `POST /api/detect`
